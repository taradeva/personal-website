# MyPortfolio

Personal portfolio mockup for Tara Devaraj.

## Preview locally

Open `index.html` directly in a browser, or run a simple local server from this folder:

```bash
python3 -m http.server 4173
```

Then visit:

```text
http://127.0.0.1:4173/
```

## Notes

- Built as a self-contained React app using CDN scripts.
- Uses React Router hash routes for case studies and the Tools page.
- Placeholder content is marked with `PLACEHOLDER` comments in `index.html`.
